# Memory game (Shrikant, 2026-11-03)

**Skill:** memory, meaning she keeps in mind where each character is (hub rule: every variation trains one named
skill). It has no number variation yet; charter AC-H6 makes those optional.

## Rules
- **M1 Characters.** Ten characters: the five companions (unicorn, superhero, princess, cute monster, gnome),
  Siara, the cup-shuffle bird, a frog, a teddy and a cat. All are drawn in the app's paper style.
- **M2 Levels.** Every card has a twin. **Easy** has 3–4 characters (6–8 cards). **Medium** has 4–6 (8–12).
  **Hard** has 6–8 (12–16). Shrikant gave tile counts, which are read as pairs.
- **M3 Opening.** Easy is always open. Medium opens after she finishes an Easy game, and Hard after a Medium
  one. A closed level is faded with a padlock. Tapping it wobbles the card and says what opens it.
- **M4 Start small.** Her first game at each level uses the level's smallest number of pairs.
- **M5 Grows with her.** If a game goes well (no more extra tries than pairs), the next one at that level gets
  one more pair, up to the level's top. If she needed more than twice the pairs in extra tries, the next game
  has one pair fewer, down to the bottom.
- **M6 Quiet.** "Find two the same. Tap a card to turn it over." is said the first time only; the ear button
  replays it. When she finds the last pair she hears "You found them all!".
- **M7 Play.** She turns two cards. A pair stays face up with a green edge and a soft chirp. Two different
  cards turn back after a second, and nothing is marked wrong.
- **M8 No extrinsic rewards.** No timers, scores or stars. Finding the last pair is the reward.
- **M9 Parent dashboard.** A Memory group shows the last ten games (level, pairs, tries), the next game size at
  each level, and a try-at-home idea.
- **M10 At home.** The ideas rotate: hide toys under cloths, play pairs with rolled socks, and remember three
  things from a walk.
